# Turtle Draw - Projeto em Progresso

**Objetivo:** Implementar pipeline completa de visão computacional + controle ROS 2 para tartaruga desenhar contornos de imagem

**Requisitos chave:**
- Visão computacional DO ZERO (sem OpenCV para processamento)
- NumPy + Matplotlib permitidos
- OpenCV apenas para carregar imagem
- Pré-processamento, detecção de bordas, planejamento de caminho
- Pacote ROS 2 completo com nó que controla turtlesim

**ROS Setup:**
- Instalado via micromamba
- Ativa: `micromamba activate ros_env`

**Entregáveis:**
1. Pacote ROS 2 completo (src/)
2. README com instruções de execução
3. Relatório técnico (máx 2 páginas)
4. Vídeo demonstração (até 4 minutos) - usuário grava

**Status:** Iniciando implementação
